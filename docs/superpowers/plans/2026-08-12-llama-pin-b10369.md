# Stage 1: llama.cpp Pin Bump to b10369 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the pinned stock llama.cpp Android arm64 runtime `b10092` with `b10369` under the Stage 1 gate of `docs/superpowers/specs/2026-08-10-performance-large-models-design.md`: pp/tg parity ±5 % on Qwen3.5 2B with thermal control, 10 clean smokes, session/abort/tool checks green. The new pin is a carrier for Stage 2 (LFM2-8B-A1B MoE) and Stage 3 (OpenCL prefill); it also gets a one-shot chance to restore strict tool grammars that `b10092`'s grammar parser could not handle (commit `6b37537`).

**Architecture:** The stock runtime is a prebuilt official release archive vendored by `tools/vendor_llama_android.sh` into `app/src/main/jniLibs/arm64-v8a/` (not stored in git), verified at build time against `app/src/main/assets/native-runtime.json` (per-ELF SHA-256) and at runtime by exact build-string checks in Java (`RuntimeScripts`, `ModelSpec`), Gradle (`verifyModelManifest`, `verifyNativeRuntime`) and the Termux-side Python runtime (`launcher._llama_in_range` against `compatibility.json`, `SERVER_FLAVOR_BUILDS`, `EXTERNAL_RUNTIME_BUILDS`). The bump flips one build string in ~14 files plus regenerated ELF hashes. The Nanbeige sidecar (`nanbeige42-c6640a1`) is a separate pin and is NOT touched.

**Tech Stack:** bash vendor script, Gradle Kotlin DSL verification tasks, Java 17 app module, Python `unittest` suites (`tests/runtime`, `tests/protocol`, `tests/tools`), adb device probes (`tools/speculative_probe.py`, `tools/adb_agent_benchmark.py`).

import json, hashlib
from pathlib import Path

manifest_path = Path("app/src/main/assets/native-runtime.json")

lib_dir = Path("app/src/main/jniLibs/arm64-v8a")

old_names = [f["name"] for f in manifest["files"]]
new_names = sorted(p.name for p in lib_dir.glob("*.so"))
assert sorted(old_names) == new_names, f"file set changed: {set(old_names) ^ set(new_names)}"

nanbeige_before = next(f for f in manifest["files"] if f["name"] == "libpideck_nanbeige_server.so")
nanbeige_before = dict(nanbeige_before)

manifest["build"] = "b10369"
manifest["commit"] = "6e62ba538478202094edc6c100c782719e310aa3"
manifest["archiveSha256"] = "9ed20985df5b243299a24636c5d086fc0fd8ea8d0c18da0662a6a113abe3272f"
for entry in manifest["files"]:

print("files rehashed:", len(manifest["files"]))
