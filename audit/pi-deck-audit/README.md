# Пакет аудита PI//DECK

Аудит от 16 октября 2026 года. Исходники: `tigrohvost/pi-deck`, коммит `43faa8b711a8d9ecf1d75b8ef86aa3fb0110ad61`.

## Файлы

- `SPECIFICATION.md` — полная русская спецификация: фактические находки, 23 пакета требований с ID, приоритеты, точки изменения, приёмка, контракты данных и последовательность внедрения.
- `reproduce_findings.py` — пять изолированных проверок исходной семантики, без сети, Android и Pi.
- `reproduction-results.json` — фактический результат запуска этих проверок в среде аудита.
- `SHA256SUMS` — контрольные суммы файлов пакета, кроме самого SHA256SUMS.

## Важное ограничение

Это не отчёт о сборке и запуске APK. Штатные Gradle/Pi tests локально не запускались; CI проверен через GitHub. Аппаратные цифры в документе — датированные результаты из репозитория, а не новые измерения.

Скрипт воспроизведения использует изолированные фрагменты семантики, а не импорт кода из checkout. Exit 0 означает воспроизведение исходных дефектов/контрактов. После исправления приложения проверять реальные функции в штатной suite, а не ожидать изменения этого скрипта.

```bash
python3 reproduce_findings.py --output reproduction-results.json
```

Начинать внедрение с пакета A в разделе 13 спецификации. Не совмещать P0-исправления со сменой модели, backend или UI framework.
